# 🤝 Contributing to SuperLauncherMC

Спасибо за интерес к **SuperLauncherMC**! ❤️

Каждый вклад делает проект лучше. Независимо от того, исправляете ли вы ошибку, улучшаете интерфейс, переводите лаунчер или добавляете новые функции — мы рады вашей помощи.

---

# 🚀 Начало работы

## 1. Сделайте Fork репозитория

Нажмите **Fork** в правом верхнем углу страницы GitHub.

---

## 2. Клонируйте свой форк

```bash
git clone https://github.com/Ludvig2457Ultra/SuperLauncherMC.git
cd SuperLauncherMC
```

---

## 3. Добавьте оригинальный репозиторий

```bash
git remote add upstream https://github.com/Ludvig2457/SuperLauncherMC.git
```

Проверьте:

```bash
git remote -v
```

---

## 4. Установите зависимости

```bash
pip install -r requirements.txt
```

---

## 5. Создайте отдельную ветку

Никогда не работайте напрямую в `main`.

```bash
git checkout -b feature/my-awesome-feature
```

или

```bash
git checkout -b fix/login-crash
```

---

# 💻 Разработка

После внесения изменений:

```bash
git add .
git commit -m "feat: add Modrinth search support"
```

Примеры хороших сообщений:

```
feat: add Fabric installer
fix: resolve launcher startup crash
docs: update README
style: improve settings UI
refactor: simplify downloader
```

---

## Отправьте изменения

```bash
git push origin feature/my-awesome-feature
```

После этого создайте **Pull Request**.

---

# 🔄 Обновление форка

Перед началом новой работы рекомендуется синхронизироваться с основным репозиторием.

```bash
git checkout main
git fetch upstream
git merge upstream/main
git push origin main
```

# ✅ Перед созданием Pull Request

Убедитесь, что:

* [ ] Код запускается без ошибок
* [ ] Не нарушена работа существующих функций
* [ ] Нет лишних файлов
* [ ] Нет временных файлов
* [ ] Нет паролей и токенов
* [ ] README обновлён при необходимости
* [ ] Изменения описаны в Pull Request

---

# 🧪 Проверка проекта

Запустите лаунчер:

```bash
python SuperLauncher.py
```

Проверьте:

* запуск интерфейса;
* загрузку версий Minecraft;
* установку Fabric/Forge;
* скачивание модов;
* запуск игры;
* обновления;
* настройки;
* создание экземпляров (Instances).

---

# 📐 Стиль кода

Рекомендуется соблюдать:

* PEP 8;
* понятные названия переменных;
* комментарии только там, где они действительно нужны;
* небольшие функции;
* минимальное количество дублирования.

---

# 🚫 Мы не принимаем

* ❌ Код, который ломает проект
* ❌ Pull Request без описания
* ❌ Большие несвязанные изменения
* ❌ Нарушение лицензий
* ❌ Вредоносный код
* ❌ Рекламу
* ❌ Спам

---

# 🐛 Сообщения об ошибках

Перед созданием Issue:

* убедитесь, что проблема ещё не была опубликована;
* приложите лог;
* укажите операционную систему;
* укажите версию Python;
* укажите версию SuperLauncherMC;
* по возможности приложите скриншоты.

---

# 💡 Предложения новых функций

При создании Feature Request желательно описать:

* какую проблему решает функция;
* как она должна работать;
* возможные альтернативы;
* примеры использования.

---
